# 3D cube reference

- `3d-cube-reference.png` is the screenshot supplied as the scene reference.
- `3d-cube.trace.json` is an editable five-point cube animation. Open it using **Open project** in Trace.
- **3D cube example** in the app opens the same scene. It preserves the preceding project in Undo history.

The map is on the left and the rendered camera on the right. Click P1–P5 in the map and drag the XYZ arrows. Camera settings start at the original Auto camera.
